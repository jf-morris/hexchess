# Hex Chess



__J.F. Morris | August 2026__



I built this browser-based hexagonal chess app (1) as an exercise in human-bot collaboration and (2) because hexagonal chess is awesome. 



Pick a variant, pick a look, and play locally against a friend or the computer. The computer is not particularly talented at the moment, but at least it plays fairly. 



No installation or anything required. The whole game is a single HTML file that runs entirely in your browser. 



If you find bugs or have feedback, please do let me know.

## Features

* **Three hexagonal chess variants**, each with its own board shape and
rules:

  * [McCooey's Hexagonal Chess](https://en.wikipedia.org/wiki/Hexagonal_chess#McCooey's_hexagonal_chess)
  * [Gliński's Hexagonal Chess](https://en.wikipedia.org/wiki/Hexagonal_chess#Gliński's_hexagonal_chess)
  * [Shafran's Hexagonal Chess](https://en.wikipedia.org/wiki/Hexagonal_chess#Shafran's_hexagonal_chess),
* **Six visual themes**, from a wood-and-felt table to Van Gogh's _The Starry Night_
* **Play against the computer**, as either color — it searches a couple of
moves ahead and picks from its best options with some deliberate
imperfection, so it doesn't play a mechanically identical game every time
* Full rules support: en passant, pawn promotion, check/checkmate/stalemate
detection, and variant-specific quirks like McCooey's f-pawn exception
* Animated moves and board flipping, undo, and a captured-pieces tray
* Auto-flip so the board always faces whoever's turn it is (or just you,
when playing the computer)
* Remembers your settings and any game in progress in the browser's local
storage — close the tab and pick up right where you left off
